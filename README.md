# Big Bang 2.4.9 Decompiled

This repo contains a decompilation for one of the earliest Android Builds of the game **Big Bang Racing** by Traplight Games.

> **📦 Game Version: `2.4.9`**

[Click here to download the original APK (32-bit)](https://world84.spcs.bio/files/view/61114985/) or [here](https://4pda.to/forum/dl/post/7470898/Big+Bang+Racing.apk)

Note: Third-party download pages may display ads or pop-ups. Please be cautious when downloading files.

# ⚠️ Important Information Before You Start

* This game originally used **Unity 5.3.0f4**, but has been updated to **Unity 5.4.0f1** (the closest version I already had).
* This project has been updated to Unity 2018.4.8f1 for stability and better support for platforms. [Click this to go to the newer source](https://github.com/Dodonickey/Big-Bang-Decompiled/tree/BigBang2.4.9-Unity2018)

* You can build for Android and Windows (because I restored the plugins 😁). iOS is buildable too, but it hasn't been tested yet. If you encounter any issues, please open an issue on GitHub to report them if related to Unity.
* Some enhancements have been made to this source, including:

  * Mouse support
  * A config file that is generated in the persistent data path (or the Internal Storage on Android, If given file permissions), making it easier to change the server URL
  * Some changes to Texture Formats to fix some issues with other devices.
  * Changes to Performance class (not much of a difference)
  * Patched out Unnecessary things which aren't needed (Analytics stuff, EveryPlay, Helpshift)

# 🛠️ How to Open the Project

## 1. Install Unity 5.4.0f1

> Unity is only required if you want to **open, modify, or build the project yourself**.

I recommend using **Unity 5.4.0f1**, as this is the exact version I used for this project.

Using a later or earlier version may cause compatibility issues.

## 2. Open the Project

After installing Unity 5.4.0f1, open this repository as a Unity project.


# 🎮 Controls

If you're running the game in the **Unity Editor on PC**, these are the controls:

* **A** — Zoom in
* **Z** — Zoom out
* **Left Shift** — Draw
* **Left Alt** — Erase
* **Left / Right Arrow Keys** — Lean Back/Lean Forward
* **Up / Down Arrow Keys** — Throttle/Brake
